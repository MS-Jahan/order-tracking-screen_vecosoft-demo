# Mobile Order Tracking UI — Autonomous Agent Implementation Plan

## 1. Project Overview & Objective
Build a production-grade, highly intuitive mobile Order Tracking screen (viewport target: 360px–430px) for an e-commerce platform. The system replaces ambiguous delivery statuses with a rich timeline, explicit ETA, item breakdown, actionable edge-state handling, and instant support channels.

The implementation must flawlessly handle three explicit scenarios:
1. **Delayed Order:** ETA crossed/rescheduled with cause transparency and escalation action.
2. **Delivered but Not Received:** Delivery confirmation dispute flow with investigation case trigger.
3. **Tracking Not Available Yet:** Pre-carrier warehouse stage without empty or broken UI states.

---

## 2. Tech Stack & Dependencies

- **Framework:** Next.js (App Router) or Vite + React 19
- **Styling:** Tailwind CSS v3.4+
- **Component Primitives:** Radix UI / Shadcn UI patterns (`Button`, `Card`, `Badge`, `Dialog`/`Sheet`, `Accordion`, `Skeleton`)
- **Iconography:** `lucide-react` (clean, unified stroke widths)
- **Micro-Interactions & Transitions:** `framer-motion`
- **Class Merging:** `clsx`, `tailwind-merge`

---

## 3. Visual System & Design Specifications

### Color Palette (Earthy Minimal Theme)
- `background-app`: `#F7F6F2` (Warm neutral desktop canvas)
- `background-mobile`: `#FFFFFF` (Surface white for mobile container)
- `brand-primary`: `#1E3A2F` (Deep Forest Green — primary buttons, hero cards)
- `brand-secondary`: `#2D5A49` (Muted Forest)
- `status-success`: `#059669` (Delivered / Active node)
- `status-delayed`: `#D97706` (Amber Ochre — warning banners, delayed badge)
- `status-alert`: `#DC2626` (Crimson — dispute, missing package alert)
- `text-primary`: `#192A24`
- `text-secondary`: `#6B7280`
- `border-subtle`: `#F1EFEA`

### Viewport & Layout Architecture
- Desktop wrapper: Centered frame, `max-w-[430px]`, `min-h-[880px]`, rounded corners (`rounded-[36px]`), subtle device bezel/shadow.
- Mobile viewport: Fluid `100%` width between `360px` and `430px`, safe padding `px-4 py-5`.
- Typography: Inter or Plus Jakarta Sans. Explicit typographic scale:
  - Header: `16px / font-bold`
  - Hero ETA: `22px / font-black`
  - Step Title: `13px / font-semibold`
  - Metadata / Microcopy: `11px / font-medium`
